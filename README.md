# DPFS_Juan_denti
Proyecto del desafío profesional e-commerce
este proyecto consiste en el desarrollo de un e-commerce de ropa diseñado para ofrecer una experiencia de compra moderna, simple y sensilla. Los usuarios podrán explorar distintas categorías de prendas, ver el detalle de cada producto, agregarlos al carrito de compras y gestionar sus pedidos de forma rápida y segura. Público objetivo: el sitio está orientado a adolescentes y adultos jóvenes que buscan ropa de calidad, con diseños actuales y una experiencia de compra online cómoda, accesible y eficiente desde cualquier dispositivo. Sobre mí: mi nombre es Juan Martín Denti y actualmente estoy cursando la carrera de Programación Web Full Stack en Digital House. Este proyecto forma parte de mi desafío profesional y tiene como objetivo aplicar los conocimientos adquiridos durante la cursada para desarrollar una aplicación web completa.
